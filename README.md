# DSH · 钉钉个人代答

基于 DeepSeek Harness 和 DWS 的个人钉钉代答插件，使用 TypeScript / React 开发。

## 功能

- 私聊及群聊 @ 消息监听、指定名单、草稿与自动发送模式。
- 全局和会话专属回复规则、回复风格、模型选择。
- 内部 AI 对话：根据对话意图发送到当前会话或调整专属规则，显示实际执行结果。
- 来信、回复、模型推理、工具调用及知识库参考片段的本地保存。
- 本地 TXT / Markdown / 问答资料，钉钉知识库浏览、预览与手动同步。
- 图片消息处理、重复消息防护、实例锁及失效锁清理。

## 开发

需要 Node.js 22+。DSH 宿主提供 React 与 `@deepseek-ai/dsh-llm` 运行时。

```sh
npm ci --legacy-peer-deps
npm run check
npm run build
```

构建结果在 `lib/`，通过 DSH 的本地插件加载机制加载项目。插件标识为 `dsh-dws-reply`，注册配置在 `cordis.patch.yml`。后端接口或运行逻辑更新后需要重启宿主。

DWS 默认路径为 `~/.local/bin/dws`，可通过宿主进程的 `DWS_BIN` 环境变量覆盖。首次使用需要关联已登录的钉钉账号、配置回复名单并保存。默认关闭监听和自动发送。

## 数据与当前限制

- 本地配置及记录位于 `$DSH_HOME/plugins/dws-reply/`；未设置时使用 `~/.dsh/plugins/dws-reply/`。
- 每个会话保留最近 100 条处理记录，每个账号最多保留最近 2,000 条；超过容量时淘汰最旧记录。兼容原有记录文件，已被旧版本清理的历史无法恢复。
- 知识库使用本地关键词检索，不是向量检索。钉钉文档使用手动同步的本地文字副本。
- 本地资料支持 TXT / Markdown；钉钉资料目前支持在线文字文档，暂不解析表格或 PDF。
- 个人微信尚未接入。
- 发送结果未知时不自动重发。真实账号及模型兼容性需在对应环境中验证。

开发规范见 [AGENTS.md](AGENTS.md)。仓库不包含运行账号配置、聊天数据、依赖目录或构建产物。

升级兼容：如果已有 `dws-personal-reply` 数据目录，插件会继续使用该目录，保留配置、聊天记录和实例锁；全新安装使用 `dws-reply`。已有 DSH 安装需将插件注册名称与本地包链接同步更新为 `dsh-dws-reply`。

## 待处理消息恢复

来信按账号写入本地 `pending-<账号摘要>.json` 后才进入模型处理；消息完成且记录保存成功后移出队列。启用监听并通过账号核验后，重启会恢复未提交发送的任务，按原接收时间校验时效，并重新检查当前回复名单。被移出名单的待处理消息保留在磁盘，重新加入名单并重启监听后才继续处理。

生成期间中断或模型失败的任务保留至下次启动恢复；明确的主人干预不恢复。提交发送前先持久化 `sending` 状态：如果随后异常退出，恢复时标记投递结果未知，不自动重发，需要核实钉钉会话。发送去重账本不再按七天淘汰，以保护长期积压任务。

本地队列覆盖已成功落盘的来信，不补拉监听离线期间未接收的消息，也不能恢复磁盘写入失败前未落盘的来信。队列包含来信正文，属于本地账号数据，不应提交到仓库。
